# 🧘 MOVE — Pilates & Bem-estar

Tecnologia a serviço do movimento, do cuidado e do bem-estar.

O MOVE é um projeto acadêmico desenvolvido pelo Grupo 06 com a proposta de facilitar a gestão de um estúdio de Pilates e bem-estar, oferecendo uma experiência digital para alunos e administradores.

A aplicação reúne informações sobre o estúdio, canais de contato e funcionalidades para gerenciamento de aulas e agendamentos, buscando tornar a organização da rotina mais simples e acessível.

## 🌿 Sobre o projeto

O MOVE foi idealizado para atender às necessidades de um estúdio de Pilates, considerando tanto a experiência dos alunos quanto as atividades administrativas.

A solução contempla uma área pública para apresentação do estúdio e acesso às funcionalidades, uma área do aluno para acompanhamento e gerenciamento de aulas e um painel administrativo para organização da agenda.

O projeto foi desenvolvido como um protótipo funcional de front-end, com navegação e interações executadas no navegador.

## ✨ Funcionalidades

- Área administrativa

## 📌 Regras de negócio

O projeto considera regras para organizar os agendamentos e garantir maior previsibilidade para alunos e administração:

O aluno deve respeitar o prazo mínimo de 24 horas para Agendamentos, alterações e cancelamentos.

Os agendamentos dependem da disponibilidade de horários.

Horários já ocupados não devem permitir novos agendamentos.

A administração pode organizar os horários disponíveis e gerenciar a agenda.

Em caso de cancelamento pela administração, o aluno deve ser comunicado e ter a possibilidade de remarcar sem prejuízo.

## ▶️ Como executar

Clone o repositório:

git clone https://github.com/KaozBR/move.git

Acesse a pasta do projeto:

`cd move`

Abra o arquivo index.html em um navegador ou utilize uma extensão de servidor local, como o Live Server, no Visual Studio Code.

Por se tratar de um protótipo de front-end, não é necessário configurar um servidor de aplicação ou banco de dados para visualizar as páginas.

## 🎓 Contexto acadêmico

O desenvolvimento do MOVE também envolveu atividades de levantamento e compreensão das necessidades dos usuários, incluindo:

- Personas: criação de perfis representativos dos públicos do sistema, considerando seus objetivos, necessidades e dificuldades.

- Mapas de empatia: identificação de comportamentos, percepções, expectativas e desafios dos usuários.

- Requisitos do sistema: definição das funcionalidades e regras de negócio a partir das necessidades identificadas.

- Diagrama de casos de uso: representação dos atores e das funcionalidades disponíveis no sistema, incluindo os fluxos do aluno e do administrador.

- Prototipação de interfaces: elaboração de protótipos de alta fidelidade no Figma, com representação das telas e dos fluxos de navegação.

- Desenvolvimento web: implementação das interfaces e funcionalidades utilizando HTML, CSS, JavaScript e Bootstrap.

- Versionamento e colaboração: utilização do Git e GitHub para organização do código e trabalho em equipe.
